# incidentiq
Repository of Python modules to manage IIQ data

# Quick Start
## Local Dev
You will need two files generated in the /secrets directory
* /secrets/secrets.json
* /secrets/svc-incidentiq-976dbf837333.json

If you do not have these files, you will not be able to build locally. 
From the command line run `python3 -m __main__.py --dev` to run all supported modules once.

## Docker
Run the following two commands to locally build the docker file. This will run the execute all supported modules once, inside the docker container.
```zsh
docker build . --build-arg COPILOT_ENV=dev --file Dockerfile --tag iiq
docker run -d iiq
```

## Secrets
Secrets are stored either in the `/secrets` folder as JSON, or in the Github repository secrets. Secrets in the Github repository are Base64 encoded and require decoding the secret and exporting it to the `/secrets` directory before any modules will run. Secrets are loaded on run. See `/secrets/example.json` for formatting.

## Code Path
`__main__.py` requires an environment flag to run in any mode other than `--dev`. Acceptable environment flags are kept in `./app/variables.py`.

Create a branch from `dev` to build features locally. Place a merge request to `dev` when your features are working and passing unit tests. Commits directly to `main` are not allowed and will be rejected.

# API Documentation
[API documentation](docs/index.html) is generated by pdoc. Run `pdoc -o docs/ app api -d google` in the root directory to regenerate API documentation.
